# 双端预览与调参 Prompt

读取材质 ID、目标视觉效果、场景、尺寸、GUI Scale、时间、指针路径与性能预算。先查目录条目、参数 Schema 和 `docs/native-preview-guide.md`、`docs/web-rendering-guide.md`。使用已有原生预览或登记的 Web Renderer。缺一端时记录该端状态和可查看的参考资源。

在独立 A/B 草稿中保留默认值和拟调整值，使用同一场景、时间和输入。逐项验证范围、步长、依赖与运行期更新能力。暂停、重置、单帧推进并检查键盘、减少动效、文字可读性和明暗背景。测试后输出参数差异、可复现操作、已量测的 GPU/CPU 指标和通过校验的预设 JSON。生产配置只在用户授权后单独提交。
